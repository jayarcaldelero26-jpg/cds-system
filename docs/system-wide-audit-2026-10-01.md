## Findings, root causes, and corrections

### 1. ENGP Completed filter â€” application defect, corrected

- **Root cause/evidence:** `SubmissionTrackingService::applyStatusFilter()` treated `date_endorsed_regional` as an ENGP legacy fallback even though the ENGP migration/model define no such field. Pre-edit isolated SQLite reproduction failed with `no such column: engp_report_submissions.date_endorsed_regional`.
- **Correction:** The ENGP Completed predicate now uses only an `EXISTS` check for matching `source_type=engp`, matching report ID, and `released_to_regional`. No replacement date or schema column was invented.
- **Regression coverage:** `tests/Feature/SubmissionTrackingTest.php` asserts a receipt-only ENGP row is excluded, an unrelated source type with the same ID does not qualify, and an ENGP regional release includes the row. `tests/Unit/SubmissionTrackingEngpCompletedFilterTest.php` and `tests/Unit/SubmissionTrackingPambCompletedFilterTest.php` now use the real ENGP column shape and cover terminal/nonterminal/source-mismatch rows. `tests/Feature/SubmissionTrackingCategoryAccessTest.php` verifies Completed results remain office-scoped for a CENRO and broad only for an authorized PENRO; its off-office action remains forbidden. Filter values and other list behaviors were not changed.

### 2. Completed PAMB mutability disagreed with timeline â€” application defect, corrected

- **Root cause/evidence:** After removing the invalid ENGP predicate, the existing completion regression exposed that `isRoutingComplete()` consulted date-based generic status for PAMB, while `SubmissionTrackingService` workspace rows use the active-cycle `PambRoutingTimelineService` result. A terminal event produced a completed workspace row but `isRoutingComplete()` returned false.
- **Correction:** For applicable Conservation/PAMB submissions, `isRoutingComplete()` now returns the PAMB timelineâ€™s canonical `routing_complete` value. Generic Conservation date behavior and ENGP event behavior remain unchanged. This keeps completed PAMB submissions read-only under existing mutation guards.
- **Regression coverage:** The existing completed-filter/routing-contract test asserts date-only legacy records and incomplete event cycles remain incomplete, while a canonical terminal event is complete and history-visible.

### 3. PAMB completed timestamp â€” stale test assertion, corrected

- **Root cause/evidence:** The failing history fixture records `PambRoutingEvent.occurred_at` as `2026-08-05 09:00:00`.
